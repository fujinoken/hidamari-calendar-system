# ひだまり現場カレンダー Ver1.3 利用者ID連携対応版

## 改修内容

- 利用者マスタに `user_id` を追加
- 予定データに `user_id` を追加
- 利用者名ではなく、利用者IDで予定と利用者を紐づけ
- 既存DB向けの自動移行処理を追加
  - 既存利用者には `U0001` 形式の仮IDを自動付与
  - 既存予定は利用者名から `user_id` を補完
- 写真メモ・Excel添付機能は維持
- Excel出力にも `user_id` が含まれます

## 起動方法

```bash
pip install -r requirements.txt
streamlit run app.py
```

## 健康管理アプリとの将来連携

健康管理アプリ側の利用者IDと、このカレンダー側の `user_id` を揃えることで、
同じ利用者の健康記録・予定・写真メモ・Excel資料を、日付軸で関連づけられます。


## Ver1.3.1 変更点

- 手書き欄のような薄い罫線スペースを追加
